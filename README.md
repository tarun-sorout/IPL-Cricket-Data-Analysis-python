# 🏏 IPL Cricket Data Analysis

This project focuses on analyzing IPL cricket data using Python. It demonstrates how to clean, explore, and visualize cricket datasets with the help of Pandas, Matplotlib, and Seaborn. The notebook contains different types of charts and analysis techniques that help understand player performance and match-related insights.

## 📌 Project Overview

The main objective of this project is to perform Exploratory Data Analysis (EDA) on IPL datasets and create meaningful visualizations for better understanding of cricket statistics.

The project includes:
- Data loading and preprocessing
- Data exploration using Pandas
- Player performance comparison
- Seasonal performance analysis
- Different data visualization techniques
- Cricket statistics analysis

5. Run all cells.
